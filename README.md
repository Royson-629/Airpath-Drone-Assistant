# Airpath-Drone-Assistant

AirPath — Drone-Guided Ambulance Corridor (Paper Presentation, SDM College Mangaluru — Finalist)

AirPath is a concept pitch for reducing ambulance response times by using a drone as an early-warning scout. The drone flies ~90m ahead of the ambulance along its route, detecting upcoming junctions in advance and triggering traffic signals to turn green before the ambulance arrives — clearing the corridor ahead of time instead of reacting to the ambulance itself.

To communicate the idea, I built an interactive SVG dashboard simulating a live control-room view: the drone and ambulance move in sync along a mapped route, junctions switch from red → yellow → green as the drone approaches, and live telemetry (speed, altitude, ETA) updates in real time — comparing a 9-minute AirPath-assisted run against a 22-minute baseline.

Presented this as a paper at SDM College, Mangaluru's paper presentation competition, reaching the final rounds.
